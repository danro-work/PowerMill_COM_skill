# COM-совместимость

Навык 0.2.3 / помощник 0.2.2 принимает ровно 2023000, 2023003 и 2023101.
Python-проверка плана и PowerShell-проверка перед отправкой команды используют
одинаковый список. Не подменяй номер версии в guard и не отключай проверки.

## Проверка 2023101 от 26.10.2026

В PowerMill 2023.1.1 проверены чтение сеанса, PID, версии, ID моделей, пути
проекта, сущности траектории, габаритов, проходов и точек; корневой HELP;
копирование, переименование и перенос отдельной копии на +100 мм глобальной X.
Проверены все 2304 рабочие точки в 1152 проходах: максимальная ошибка
переноса 0.000002862 мм, оси инструмента и векторы ориентации не изменились.
Исходная траектория сохранила ID, настройки, габариты и все рабочие точки.

Это ограниченная нативная квалификация. Она не подтверждает расчёт новых
поверхностных стратегий, сортировку, ПП, восстановление после реального сбоя
или роботную симуляцию на 2023101. Проверки переходов/коллизий не выполнялись.
Протокольные тесты используют подставное приложение и запрещают GetActiveObject.

## Копирование и перенос

Перед COPY зафиксируй имена и ID траекторий. COPY TOOLPATH "SOURCE" создаёт
копию с автоматически выбранным именем; прочитай фактическое имя и новый ID,
затем выполни RENAME TOOLPATH "ACTUAL_COPY" "TARGET". Не угадывай имя копии.

Для проверенного переноса использовалась последовательность:

```text
TRANSFORM RESET
TRANSFORM TYPE MOVE
TRANSFORM MOVEX 100
TRANSFORM MOVEY 0
TRANSFORM MOVEZ 0
TRANSFORM COPY OFF
TRANSFORM TOOLPATH "TARGET"
```

Глобальная система обеспечивалась отсутствием активной рабочей плоскости;
это проверялось как предусловие. При активной рабочей плоскости сначала
определи нужную систему координат и согласованный способ её использования.
Не считай приведённые команды автоматически глобальными при иной плоскости.
Выполняй через Executor с проверками ID, координат и сохранности исходника,
тайм-аутами и checkpoint до отправки; при неопределённом исходе не повторяй
относительный сдвиг автоматически. Нативный код 0 проверяй по фактическим точкам.
